# 그림 넣는 곳

소정님이 직접 그린 그림을 넣는 폴더입니다. **파일만 바꿔 넣으면 앱에 바로 반영돼요.**

## poop/ — 똥 크기 비교 그림

지금은 제가 대충 그려둔 임시 그림이에요. 같은 이름으로 덮어쓰면 그대로 바뀝니다.

| 파일 | 뜻 |
|------|-----|
| `pellet.svg` | 염소똥 — 작고 동글동글 |
| `short.svg` | 짧음 — 손가락 절반 |
| `normal.svg` | 보통 — 성인 손가락 하나 |
| `long.svg` | 긺 — 손가락보다 길거나 여러 덩이 |

**그릴 때 참고**
- 가로로 긴 비율(가로 100 : 세로 60 정도)로 그려주세요
- SVG가 제일 좋아요. PNG로 그리셨으면 파일명만 알려주시면 제가 맞춰둘게요
- 네 장이 **나란히 놓였을 때 크기 차이가 한눈에 보이게** 그리는 게 핵심이에요

## avatars/ — 고양이 아이콘

리온·레오 이름 앞에 붙는 그림이에요. 지금은 애플 이모지만 쓰고 있고, 여기 그림을 넣으면 **이모지 대신 고를 수 있게** 됩니다.

**그릴 때 참고**
- 정사각형, 동그랗게 잘려도 괜찮게 여백을 두세요
- 작게(24px) 보여도 알아볼 수 있게 단순하게
- 파일명은 영어로 (예: `lion.svg`, `leo.svg`, `nabi.svg`)

**넣은 뒤에** `avatars/manifest.json` 에 파일명을 추가해야 앱이 알아봐요. 직접 고치기 번거로우면 그냥 저한테 "아바타 그림 넣었어" 하고 말씀해주시면 제가 연결할게요.

## 나중에 (판매할 때)

사용자 반려동물을 소정님 스타일로 그려주는 서비스를 하실 계획이라, 이 폴더 구조가 그대로 확장돼요. 지금은 파일로 관리하지만 그때는 서버에서 받아오는 식으로 바꾸면 됩니다.
